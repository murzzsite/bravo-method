Бот подключён, но не отвечает: что проверить в сообществе

Ключ доступа принят и бот привязан к сообществу «Метод БРАВО». Чаще всего он молчит из-за одной из настроек в VK. Пройдите три шага, они занимают несколько минут.

Сообщение от нас

Бот в вашем сообществе подключён, но пока не отвечает

Скорее всего, не включена одна из настроек в VK. Проверьте, пожалуйста, по пунктам в сообществе «Метод БРАВО»:

  1. Управление → Сообщения: «Сообщения сообщества» включены, и там же «Возможности ботов» включены.
  2. Управление → Работа с API → Long Poll API: включён, версия API самая новая. Вкладка «Типы событий», раздел «Сообщения»: отмечено «Входящее сообщение».
  3. Ключ доступа создан в этом же сообществе, с правом «Сообщения сообщества».

Когда проверите, напишите нам «готово», и мы подключим заново. Если какой-то пункт не получается найти, пришлите скриншот именно этого экрана.

1. Сообщения сообщества

  • Откройте сообщество, «Управление», «Сообщения».
  • «Сообщения сообщества» должны быть включены.
  • Там же, в «Настройках для бота», включите «Возможности ботов».

2. Long Poll API

  • «Управление», «Работа с API», вкладка «Long Poll API».
  • Long Poll API включён, версия API самая новая из списка.
  • Вкладка «Типы событий», раздел «Сообщения»: поставьте галочку «Входящее сообщение». Если её нет, бот не получает сообщения и молчит.

3. Ключ доступа

  • «Управление», «Работа с API», вкладка «Ключи доступа».
  • Ключ должен быть создан в этом же сообществе с правом «Сообщения сообщества».
  • Если сомневаетесь, создайте новый ключ и пришлите нам в рабочий чат. Старый удалите.
Когда проверите: напишите нам в рабочий чат «готово». Мы подключим бота заново, пришлём ссылку, и вы сможете проверить, нажав «Начать». Если какой-то экран отличается от описания, пришлите скриншот именно его.

Ключ доступа нужен только для подключения бота. Присылайте его в рабочий чат с нами и не публикуйте нигде в открытом виде.
